## DeepWiki MCP
GitHub リポジトリのドキュメント・コードベース理解に使用。
### 使用方法
`mcp_deepwiki_ask_question` ツールを使用:
repoName: "owner/repo" (例: "facebook/react") question: 具体的な質問

### 効果的なクエリ例
- 「CSS テーマ設定システムはどのように機能しますか？」
- 「どのようなプラグインが利用可能で、どのように使用しますか？」
- 「コントローラーやイベント処理を含むコアアーキテクチャは何ですか？」
### Tips
- 質問は具体的にする
- 「このリポジトリについて教えて」のような曖昧な質問は避ける
