## DeepWiki MCP
GitHub リポジトリのドキュメント・コードベース理解に使用。
### 使用方法
`mcp_deepwiki_ask_question` ツールを使用:
- repoName: "owner/repo" (例: "facebook/react")
- question: 具体的な質問
### このプロジェクトの依存関係マッピング
| npm パッケージ | DeepWiki リポジトリ名 |
|---------------|----------------------|
| `@xpadev-net/niconicomments` | `xpadev-net/niconicomments` |
| `anime4k-webgpu` | `Anime4KWebBoost/Anime4K-WebGPU` |
| `neverthrow` | `supermacro/neverthrow` |
| `zod` | `colinhacks/zod` |
| `@crxjs/vite-plugin` | `crxjs/chrome-extension-tools` |
| `@resvg/resvg-js` | `linebender/resvg` |
| `nodemon` | `remy/nodemon` |
| `oxlint` | `oxc-project/oxc` |
| `prettier` | `prettier/prettier` |
| `typescript` | `microsoft/TypeScript` |
| `vite` | `vitejs/vite` |
| `vite-tsconfig-paths` | `aleclarson/vite-tsconfig-paths` |
### 効果的なクエリ例
- 「CSS テーマ設定システムはどのように機能しますか？」
- 「どのようなプラグインが利用可能で、どのように使用しますか？」
- 「コントローラーやイベント処理を含むコアアーキテクチャは何ですか？」
### Tips
- 質問は具体的にする
- 「このリポジトリについて教えて」のような曖昧な質問は避ける
